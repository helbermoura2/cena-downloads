# CENA — atualizações para Android

[Ver e baixar a versão mais recente](https://github.com/helbermoura2/cena-downloads/releases/latest)

Instale sobre a versão existente para manter seus dados. No aplicativo, acesse Conectar → Atualizações do CENA para verificar futuras versões. O Android pedirá sua confirmação para instalar.

A disponibilidade de streaming no Brasil usa TMDB e JustWatch e requer uma chave de API v3 configurada no aparelho. O código de desenvolvimento e a chave de assinatura permanecem privados.
